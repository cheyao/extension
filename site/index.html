Swissquote Wallet is a browser extension wallet. Install the demo build below to try it in Chrome or any Chromium browser.

Install Swissquote Wallet
1

Download the build

Click Install Swissquote Wallet to download chrome.crx to your computer.

2

Open extensions

Go to chrome://extensions and turn on Developer mode (top right).

3

Load it

Drag chrome.crx onto the extensions page, then confirm the install prompt.

Swissquote Wallet is an independent hackathon demo build and is not affiliated with, endorsed by, or connected to any financial institution. Install developer builds only from sources you trust.
