# Swissquote contract registry (demo database)
#
# Stand-in for Swissquote's server-side registry. Instead of trusting
# addresses, Swissquote reviews the *code* that runs at a contract: the wallet
# downloads the contract's bytecode (eth_getCode), hashes it with SHA-256 and
# compares the hash with the verdicts below. If the code at an address ever
# changes, its hash changes too and the previous verdict no longer applies.
#
# Hash definition: SHA-256 of the raw runtime bytecode bytes returned by
# eth_getCode (hex-decoded, without the 0x prefix), written as 64 lowercase
# hex characters. Proxies are hashed as deployed (the proxy's own code).
#
# Line formats (blank lines and # comments are ignored):
#
#   dapp <domain> <chain id> <contract address> [label]
#       A contract the dApp at <domain> runs. Subdomains match too, so
#       "uniswap.org" covers "app.uniswap.org". Chain id is hex (0x1) or
#       decimal (1). These are the contracts checked when the site connects;
#       for transactions the wallet always checks the contract being called.
#
#   safe <sha256>      Code Swissquote has reviewed and deems safe.
#   unsafe <sha256>    Code Swissquote deems unsafe (blacklist).
#
# Any other code hash is "not recognised".
